# Flujo básico de Git y GitHub: Pull / Commit / Push

Este documento describe el flujo de trabajo básico más común al usar **Git** junto con **GitHub**.

---

## ¿Qué es Git y qué es GitHub?

- **Git** es un sistema de control de versiones distribuido. Permite registrar cambios en archivos, volver a versiones anteriores y trabajar de forma segura en proyectos.
- **GitHub** es una plataforma en la nube que aloja repositorios Git y facilita la colaboración entre desarrolladores.

Git funciona de forma local en tu ordenador. GitHub actúa como repositorio remoto.

---

## Flujo Pull → Commit → Push

Este es el ciclo habitual de trabajo cuando colaboras en un proyecto.
